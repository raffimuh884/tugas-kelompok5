Project ini merupakan tugas kuliah kelompok yang berfokus pada proses data cleaning, data preprocessing, dan visualisasi data menggunakan Jupyter Notebook, kemudian hasilnya diimplementasikan ke dalam bentuk web sederhana.

Dalam project ini, kami diberikan sebuah dataset mentah yang kemudian dilakukan proses:

- Pembersihan data (data cleaning)
- Penanganan missing value
- Transformasi data
- Analisis sederhana
- Visualisasi data

Setelah data siap digunakan, hasil analisis tersebut diimplementasikan ke dalam sebuah website sederhana untuk menampilkan hasil secara interaktif.
